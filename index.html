Master PIN protection

Set one company PIN once. The app checks this PIN before each deletion. This free version protects against accidental deletion, but it is not server-enforced security. Choose 6–12 digits and share it only with trusted staff.

Backup & restore

Export a JSON backup regularly. Browser data can be lost if you clear website data or change devices before Firebase sync is configured.

About driver calculations

Each trip stores its own individually entered driver-pay amount; no fixed driver rate is assumed. Later rate changes won't rewrite older trip earnings. Advances, deductions and settlements are tracked separately so you can see the outstanding driver balance.
